🌍 Text Translator Web App

A simple and powerful web application that translates text from one language to another instantly.
This project allows users to enter text, choose source and target languages, and get fast translations in a clean and user-friendly interface.

🚀 Features

🌐 Translate text between multiple languages

🔄 Select source and target languages

⚡ Instant translation

🎨 Clean and responsive UI

📱 Works on mobile and desktop

🛠️ Built With

HTML5

CSS3

JavaScript

⚙️ How To Use

Enter the text you want to translate.

Select the source language.

Select the target language.

Click the Translate button.

View your translated text instantly.
